## 課題概要

タスクバーの上を、猫が歩いたり、座ったり、丸まって寝たりして過ごす、癒し系のデスクトップペットを制作しました。
猫を左クリックで押さえたままマウスを動かすとつかんで持ち上げることができます。

### 生成AIに入力した内容

実際に入力した内容（代表的なもの）：

> 「processingを用いてタスクバーの上に何らかのものや動物が動くものってつくれるの？」

> 以下の仕様で、Windowsのタスクバーの上を歩く猫のデスクトップペットを作ってください。コードは1つのpdeファイルにまとめてください。
>
> 【目的】
> Windowsのタスクバーの上を猫が歩き、見ていて癒されるデスクトップペットにしたい。
>
> 【環境・条件】
> - Processing / Windows
> - 追加ライブラリ・画像ファイル・音声ファイルは使わない
> - 猫は、プログラムの図形で表現
> - コードには、わかりやすい日本語のコメントをつけてください
>
> 【表示】
> - 猫の背景は透明にする。
> - タスクバーは画面の下にある前提で、猫の足がタスクバーの上端に乗るようにする
>
> 【猫の動き】
> - 「歩く・座る・寝る」をランダムに切り替える。画面のはしでは折り返す
> - 歩くときは、足としっぽが自然に動く。座っているときはまばたきをする。寝ているときは、目をつむりZzzが出るようにする
>
> 【マウス操作】
> - 猫を左クリックで押さえたまま動かすと、つかんで持ち上げられる
> - つかまれた猫は、びっくりした顔で手足をばたつかせ、じっとしていると目を閉じて落ち着いた顔をする
> - マウスを横に動かすと、体がぶらんぶらん揺れる（振り子のような動き）
> - はなすと、重力で落ちてタスクバーの上に着地し、着地でぷにっとつぶれる。動かしながらはなしたときは、その勢いで飛ぶ
> - 右クリックで終了する
>
> 【設定】
> - 猫の大きさ・歩く速さ・色を、コードの定数で簡単に変えられるようにする
>
> 【出力】
> - 完成したコードと、実行方法・操作方法を簡潔に説明してください

### 生成AIから得たものをどのように利用したか

生成AIが作成したプログラムをベースに、猫が動く作品として利用しました。

生成AIが作成したコードを実際にProcessingで実行し、猫が透明な背景でタスクバーの上を歩くこと、つかんで動かせること、右クリックで終了することを確認しました。

## 実行方法

### Processingで実行する場合

1. GitHubからリポジトリをダウンロードする
2. `taskbar_cat` フォルダをProcessingで開く
3. `taskbar_cat.pde` を開く
4. Processingの「実行」ボタンを押す
5. 終了するときは、猫を右クリックするか、Processingの停止ボタンを押す
